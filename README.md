# CP Lab Programs

This repo contains the CP lab programs arranged week-wise for the 9-week schedule.

### Week 1
- Factorial using recursion
- Calculate the length of a string
- Interchanging numbers in an array
- Maximum subarray sum

### Week 2
- Merging two sorted arrays
- Majority element
- Maximum ascending subarray sum
- Counting Sort - 1

### Week 3
- Counting Sort - 2
- Median of two sorted arrays
- Division using binary search
- Bucket Sort

### Week 4
- Add two numbers using bit manipulation
- Check K-th bit
- Find the triplets
- Count set bits

### Week 5
- 3N+1 Problem
- HackerRank in a String
- Find duplicate characters using bit manipulation
- Border of a string

### Week 6
- Period of a string
- Camel Case
- Pattern searching
- Trie (Insert and Search)

### Week 7
- Extended Euclid with Bezout's Coefficient
- Water Jug Problem
- Ford Fulkerson Algorithm
- Wild Card Patterns

### Week 8
- Coin Change Problem - 1
- Coin Change Problem - 2
- Minimum Cost Path
- Rotten Oranges

### Week 9
- Spirally Traverse Matrix
- Tug of War

The programs are kept as simple C++ practice programs for the CP lab and are arranged in the same order as the lab list.
